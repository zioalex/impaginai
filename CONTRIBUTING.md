# Contributing

Contributions are welcome: bug reports, fixes, templates, translations and
lab specifications.

1. **Sign the CLA once.** Read [`CLA.md`](CLA.md) and add the sentence from its
   "How to sign" section to your first pull request. It lets the project be
   offered under the AGPL-3.0-only and under commercial licences; you keep your
   copyright. We cannot merge code without it. If your change was written with
   an AI assistant, say so in the pull request (`CLA.md` section 4.4).
2. **Set up and test the way CI does.** The commands are in
   [`AGENTS.md`](AGENTS.md) (`pytest --cov` and `ruff check .`).
3. Keep a pull request to one change, say what you ran, and update the
   docs when behaviour changes.

### Keeping it machine-readable

The repository follows the [REUSE specification](https://reuse.software), so
every file says what it is licensed under and a tool can read it:

- Licence texts live in `LICENSES/`, each named by its SPDX identifier.
  `reuse download <SPDX-id>` adds one. `LICENSE` at the root is the same AGPL
  text again, because that is where GitHub looks for it.
- New source files carry the two `SPDX-FileCopyrightText` and
  `SPDX-License-Identifier` lines that the existing ones have.
- Files that cannot hold a comment, are regenerated by a tool, or are meant to
  be copied by users are covered by globs in [`REUSE.toml`](REUSE.toml).
- `pipx run reuse lint` must pass; CI runs it. `reuse spdx` prints the whole
  bill of materials.
