# Floors, not exact pins.
#
# The first version of this file pinned whatever happened to be installed on the
# machine it was written on, which was months behind, and produced 64 Dependabot
# alerts across pillow and pypdf. Both libraries parse untrusted binary input —
# photographs and PDFs — so they are exactly the two that must not lag.
#
# `>=` lets a fresh install pick up security releases without this file being
# edited. If you need byte-identical rebuilds, generate a lock file from this:
#
#     pip install pip-tools
#     pip-compile requirements.txt -o requirements.lock.txt
#     pip install -r requirements.lock.txt
#
# Check for new advisories at any time with:
#
#     pip install pip-audit && pip-audit -r requirements.txt
#
# Versions in the comments are what this was last verified against.
